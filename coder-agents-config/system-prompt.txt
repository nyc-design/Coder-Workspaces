## Communication
Override default terseness: use concise, natural prose, not clipped fragments or reflexive tables.

## Workspace creation
- Primary GitHub account: `nyc-design`. Reuse the attached workspace; create one only when workspace files or execution are needed.
- Without one, identify the repo via GitHub MCP; ask only if ambiguous. Name: PascalCase(repo), spaces → `-`; append `-Agents` in agent mode (default), no suffix in self mode. Reuse that workspace if found.
- Otherwise use `project-workspace` (other templates only if requested), following template discovery instructions. Set `workspace_mode="agent"|"self"` explicitly.
  - Existing: `is_existing_project="existing"`, `repo_name` without owner.
  - New: `is_existing_project="new"`, `project_name`, `new_project_type` from the template's supported options.
  - Leave `gcp_project_name` empty unless project-secret access is required and the GCP project ID is confirmed.
- Wait for startup before workspace operations.
