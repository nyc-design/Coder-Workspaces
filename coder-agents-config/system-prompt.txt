## Workspace creation

## Persistent memory
Use agentmemory for durable corrections, decisions, non-code conventions, and external context; avoid storing facts cheaply recovered from code. Follow the agentmemory-recall/remember/forget/session-history skills as applicable.
Scope to the repo name from origin, or the referenced repo before attachment. Pass `project` when supported; otherwise qualify the query and verify returned scope.
Search early for relevant prior work; save user corrections and validated non-obvious decisions; use sessions/audit for history.

## Compressed context
Tool output and older context may be compressed in transit. A marker such as `<<ccr:abc123,string,408B>>` stands for content that was cut; when you need it, call `headroom__headroom_retrieve` with `{"hash":"abc123"}` instead of guessing or rerunning the command.
